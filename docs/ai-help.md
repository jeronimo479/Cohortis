# partyFragment
The panel on the main screen that shows the active parties.

# partyLibrary
The panel that shows all the parties and if they are currently displayed by partyFragment.

# memberLibrary
The panel that shows all the members.

# editMember
The panel that shows all the member traits.

# EventFragment
The panel on the main screen that shows events.

# RoundCounter
The Cirlce on the main screen that shows what round it is.

Tap increases round counter. Double tap decreases round counter. Tap and slid left rsets to zero.

Application setting, include load, save JSON, and 'Master Reset'
